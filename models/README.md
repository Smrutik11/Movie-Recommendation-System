# Trained Model

This folder contains the trained SVD matrix factorization model used by the Streamlit recommendation application.

## Model

- **Algorithm:** Singular Value Decomposition (SVD)
- **Library:** Scikit-Surprise
- **Purpose:** Predict user ratings for unseen movies and generate Top-N movie recommendations.

The trained model is saved as:

`svd_model.pkl`

The model is generated from the MovieLens 100K ratings dataset.
